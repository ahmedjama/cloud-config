# cloud-config

Cloud-config files for Multipass VMs.

- [`opencode/`](opencode/) — Ubuntu 24.04 dev VM for agentic AI development.
  Includes OpenCode, Python/uv, Node/pnpm/Bun, Docker, Starship, and SSH-ready
  shell tooling. See [`opencode/README.md`](opencode/README.md) for launch and
  SSH instructions.
- [`cloud-init.yaml`](cloud-init.yaml) — small generic example.
- [`multipass-launcher.sh`](multipass-launcher.sh) — helper for launching a
  configured VM.
